# Changelog

All notable changes to Frost Studio DAW are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Runtime preset loading: `get_synth_presets` reads `src-tauri/presets/**/*.json`,
  falling back to the in-memory factory bank.
- Sample-rate agnostic engine: `MixerState` tracks the device sample rate and
  rebuilds all DSP (synths, effects, mixer, clock) via `set_sample_rate`. WAV
  export now uses the engine's rate.

### Planned (see [ROADMAP.md](ROADMAP.md))
- Project save/load (`.frost` files)
- Audio track editing (trim, fade, clip)
- Sampler velocity layers and round-robin
- MIDI recording and metronome

### Docs
- Corrected compressor parameter ranges to match actual clamps.
- Clarified that `frost-core` is a workspace member, not a git submodule.
- Updated `get_synth_presets` docs to describe disk-first loading.
- Noted the sample-rate agnostic engine in the developer guide and DSP reference.
- Flagged `src/presets/pro-trap-neo.json` as not wired to the engine.

## [0.1.0] - 2026-01-01

### Added
- Real-time audio engine on a dedicated thread via **CPAL**.
- Shared DSP library (`frost-core`) used by both the DAW and standalone plugins.
- **4-channel mixer** with per-channel:
  - 3-band EQ (low shelf, mid peaking, high shelf)
  - Constant-power panning and volume fader
  - Mute / solo / sidechain ducking
  - Reverb and Delay send buses
  - Insert chain for native plugins
- **Master bus** with look-ahead brickwall limiter and RMS/peak metering.
- **4 built-in instruments**:
  - Summit — Moog-style wavetable synthesizer (ZDF ladder filter)
  - Eruption — Korg MS-20-style subtractive synth (Sallen-Key filters)
  - Nebula — wavetable / FM hybrid synth
  - Sampler — one-shot and pitched sample playback
- **7 built-in effects** (insert plugins):
  - Compressor, Parametric EQ, Limiter, Bass enhancer, Delay, Reverb, Distortion
- **MIDI piano roll** with note sequencing.
- **Arrangement view** with audio clip tracks and beat-synced playback.
- **Offline WAV export** (`Exporter::export_to_wav`).
- **VST3 plugin hosting** (Windows): bundle scanning + `libloading` host engine.
- **6 standalone plugins** exporting VST3 and CLAP via `nih-plug`:
  - Frost Compressor, Frost EQ, Frost Limiter, Frost Bass, Frost Delay, Frost Reverb
- **Sample browser** with recursive filesystem scanning.
- **Real-time visualizer** (spectrum / oscilloscope via Three.js).
- **Undo/redo** via Zundo temporal middleware on the Zustand store.
- **GitHub Actions CI** building Windows (MSI/NSIS), macOS (DMG), Linux (DEB).
- **150 factory presets** (50 each for Summit, Eruption, Nebula) generated by
  `scripts/generate_presets.cjs`.

### Fixed
- Documentation aligned with the actual codebase (directory names, synth list,
  preset storage, toolchain).
